usage: codebreaker <command> [arguments]
       codebreaker               with no command: the CodeBreaker window
       codebreaker <command> --help    what a command does and its options

    convert FILE                    turn a program into source code you can read and build
    inspect FILE                    say what a file is and what is inside it
    extract FILE                    take the files out of a disc image, cabinet, archive, package or font file
    build FOLDER                    make a program again from its source folder, and check it against the original
    check FILE                      prove that rebuilt source behaves like the original (or matches its bytes)
    compare A B                     match two builds of a program, function by function
    corpus                          work on the whole collection: run it, watch it, score it
    lookup NAME                     explain a name, a service call or a signature
    xbox                            Xbox 360 tools: edit and re-sign a program, crypto, recompiler setup

Also:
    settings                        every setting, and whether what it names is there
    cache                           what the cache keeps; prune or clear it (--tidy cleans <state>, --migrate carries
                                    old results over)
    regress <all15|setup|slow>      the milestone regression: the 15 MINI.CAB modules rebuilt and booted to Setup's
                                    License page, the Setup chain, the slow cases
    serve                           the CodeBreaker service: one process the MCP servers and `facts` all ask (started
                                    on demand; exits when idle)
    mcp                             CodeBreaker as an MCP server for an assistant (stdio; or HTTP with a token)
    app                             the CodeBreaker window, what `codebreaker` starts with no command; --screenshot
                                    PNG draws it to a file
    disassemble FILE                CodeBreaker's disassembler: any program or ROM, for any processor (`disassemble
                                    --list`)
    assemble SOURCE --cpu NAME      CodeBreaker's assembler: source for any processor to its bytes (`assemble --list`)
    compile SOURCE.c                CodeBreaker's compiler: C to an object, in this program (OpenWatcom's wcc /
                                    wcc386)
    link <linker arguments>         CodeBreaker's linker: objects to a program, in this program (OpenWatcom's wlink)

`--corpus NAME` before or after any command selects another product's files (settings.json: corpora).
