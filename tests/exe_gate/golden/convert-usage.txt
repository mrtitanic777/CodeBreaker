usage: codebreaker convert FILE [--to LANG] [--out DIR] [--languages]

Turn one file back into source code, as the CodeBreaker window does. The stages the file passes through and the share of the
work done are printed; the source goes next to FILE as <file name>-converted/ (or under the folder the setting converted
names, or to DIR), in a folder that did not exist before: a numbered
sibling (name_2, name_3 ...) when it would have. Exit code 0: done; 1: failed; 3: CodeBreaker cannot convert this kind of file.

FILE may also be source code (.cs, .py ...): --to LANG says which language to translate it to (original, the default, keeps the
file's own source and is for programs). The translator is asked which languages it can write for FILE; the translation is built and
run beside the original, and the run is done only when both do the same (otherwise it fails and nothing is kept). --languages
lists the languages the translator can write for FILE, with the reason for each it cannot, and converts nothing.
