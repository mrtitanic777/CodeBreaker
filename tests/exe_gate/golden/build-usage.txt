usage: codebreaker build FOLDER [--against F] [--out DIR]

make a program again from its source folder, and check it against the original

FOLDER is a source folder; build looks at what is in it: a driver's assembly, a DOS program's assembly, or a 16-bit DLL's C. A .toml file is a
recompiler configuration. A module name or a file is the whole-module build, as before. Name the kind to be sure.

options:
  --module          the whole-module build: a corpus name or a file, built from its recovered source and checked
  --dos             that program made again from its source folder alone
  --driver          assemble and link a driver, check it against the original
  --resources       a module's resources as .rc and files, compiled and compared
  --floppy          the Win95 Setup boot floppy, made from the rebuilt files
  --disc            write a CD image (also --list, --extract)
  --xenon           XenonRecomp on a configuration, its output folder synced (changed files in, stale ones out): what
                    a build runs, the Xbox 360 Dashboard's modules too

Old names (they still work, and print what they always did):
  dos-build          = build FILE --dos
  driver-build       = build FILE --driver
  resources          = build FILE --resources
  boot-floppy        = build FILE --floppy
  disc               = build FILE --disc
  xenon-recompile    = build FILE --xenon
